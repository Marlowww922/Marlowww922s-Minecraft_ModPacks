# Marlowww-Minecraft-pack
Marlowwww's Minecraft mod pack (all mods) 

To use this mod correctly you, have to Open up Minecarft java edition (Marlowww Java.zip) - file, and then click on options and then resource pack and then upload this zip file (Marlowwww Java.zip)

For Bedrock players - Download this Mod and then open up files (Android or IOS) and then double click on the file (Marlowww bedrock.mcpack) and it will open up Minecraft and enjoy the mod! (Or just click on the three dots on the top right after you click on the file once and select Minecraft)

# Mod Pack instructions 
Open up the mod pack in files (Double click Zip) and it should turn into a folder. Open the folder
And open up Minecraft Launcher, but first have the Fabric API mod and the Mod loader downloaded to open up the Launcher and go to the play and then click on the down arrow and click select mod and then the Modpack  folder and then Marlowww Vanilla Plus CPVP Optimizer (I think its called that).
